# Meta Quest 3 Soundboard Project

This project is dedicated to creating a customizable soundboard for the Meta Quest 3 VR headset. The goal is to allow users to easily play sound clips during their virtual reality experiences, enhancing immersion and interactivity.

## Features
- Easily add and manage sound clips.
- User-friendly interface for sound management.
- Supports a variety of audio formats.

## Setup Instructions
1. Clone the repository:
   ```
   git clone https://github.com/mariofoquita-bot/Bbb.git
   ```
2. Navigate to the directory:
   ```
   cd Bbb
   ```
3. Install the required dependencies:
   ```
   npm install
   ```
4. Run the application:
   ```
   npm start
   ```
